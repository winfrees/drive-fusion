# drive-fusion

A desktop tool for cataloging every drive you own — internal, external, connected or
shelved — confirming how many real copies of each file exist, and building safe,
reviewable plans to consolidate that content into a traceable order.

Python 3.11+ · PySide6 GUI · SQLite catalog · packaged as a standalone executable.

**Status:** design phase. See [docs/PLAN.md](docs/PLAN.md) for the full build plan —
architecture, data model, risk scoring, the placement planner, and milestones M0–M7.
